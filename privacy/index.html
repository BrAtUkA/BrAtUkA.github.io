Privacy Policy

Last updated: July 2026

Summary

This policy describes the root portfolio at bratuka.dev. The portfolio has no accounts, forms, advertising trackers, or analytics scripts. Separately deployed tools can have different network behavior, described below and in their own documentation.

Root Portfolio

The root portfolio does not intentionally collect or store personal information. It requests public profile and repository statistics from the GitHub API and displays them on the page. Its interface fonts and scripts are served from bratuka.dev rather than third-party font or script CDNs.

Tool Properties

PDF Dark Mode Converter: PDF contents are designed to be processed in your browser rather than uploaded to a BrAtUkA server. The application loads dependencies and may load analytics resources over the network, so local file processing should not be read as a claim that the whole page makes no network requests.

Claude Widgets Viewer: imported artifacts are stored and rendered in the browser. Because imported artifacts can contain active HTML and JavaScript, their own code may make network requests. Only open files you trust.

Other tools linked from the portfolio may be separate applications with their own dependencies, hosting, and privacy documentation. Their repository source is the most specific record of their current behavior.

No Portfolio Accounts or Profiles

The root portfolio has no user accounts, tracking profiles, contact form, or application database. Choosing the email link opens your own mail client; any message you send is handled by your email provider and the recipient's email provider.

Local Storage

To reduce GitHub API requests, the portfolio caches public GitHub statistics in your browser's local storage for up to one hour. It also stores your visual-effects preference until you change it or clear your browser data. The portfolio reads these values locally; it does not send them to BrAtUkA.

Third-Party Requests and Hosting

The root portfolio is published through GitHub Pages and requests public data from the GitHub API. When your browser connects to GitHub, it receives normal request information such as your IP address, user agent, requested resource, and timestamp, subject to GitHub's policies. Linked tools may use different providers.

Public Source

Source code for the portfolio and many linked tools is publicly available on GitHub for inspection. Licensing differs by repository; public source availability does not by itself grant an open-source licence.

Contact

If you have any questions about this policy, contact bratuka@bratuka.dev.
