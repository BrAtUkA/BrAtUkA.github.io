What it does

You type a goal, like open Disk Management or search for flights to New York, and press Start Agent. It takes a screenshot, decides what to do, moves the mouse, clicks and types, and repeats until the task is done or it runs out of steps. You can watch it think as it goes and stop it at any time.

Everything runs on your own machine. There’s no cloud API: the model is Holo2-4B from H Company, a 4-billion-parameter vision-language model tuned for using computer interfaces, loaded in 8-bit so it fits on a laptop GPU.

One model, three roles

Deciding what to do next and finding exactly where that is on the screen are different jobs. So the same model plays three roles, each with its own prompt.

  • Navigator. Sees the screenshot, the goal and the history of earlier steps, then writes its reasoning and picks the next action, like click the Start button or type “Disk Management” and press Enter.
  • Localizer. Gets the screenshot and a short description of the target, and answers with its position on a 0 to 1,000 grid. That’s scaled to your actual screen, so it works at any resolution.
  • Validator. Optional. After an action, it checks whether it worked, and its verdict goes into the history so the Navigator can correct course.

Each role answers in structured JSON, checked against a Pydantic model before anything happens on screen.

What it can do

The Navigator chooses from a small set of actions: click an element, type into it, type and press Enter, scroll, go back, refresh, wait, or give the final answer. Keeping the list short makes the model’s job easier and its mistakes easier to spot.

There are four speed presets, which set how large the screenshot is before the model sees it. Smaller is faster but can miss small buttons.

Testing each part

The Gradio interface has a tab for each role as well as the autonomous mode. You can upload a screenshot and ask the Localizer where something is, or ask the Navigator what it would do next, without letting it touch the mouse. That makes it easy to see which part is getting things wrong.

What changed in v2

The first version, in June 2025, used Holo1.5-3B. In February 2026 I moved it to Holo2-4B, which improved both accuracy and reasoning.
