Why I built it

Knox hybrid inverters send their readings to the ShineMonitor cloud every five minutes. To see them you have to open a phone app or a website. When the grid goes down, the inverter switches to battery and nothing tells you.

KnoxHybrid Monitor lives in the Windows system tray. It shows the inverter’s status, alerts you as soon as the house switches to battery, and alerts you again when the grid comes back, with how long the outage lasted. It is meant to run all day, so it had to use almost no memory or CPU.

How it works

Many monitors ask the server for new data every few seconds, even when nothing has changed. The inverter only reports every five minutes, so checking more often than that is wasted work. This app looks at when the latest reading was taken, works out when the next one is due, and sleeps until then.

In more detail:

  • It sleeps between readings. After a new reading it waits about 250 to 290 seconds, the rest of the five-minute window. During that time Windows doesn’t run it at all.
  • It retries when data is late. If a reading is overdue, it checks every 30 seconds for up to ten minutes. If the server is down, it waits longer between tries, from 30 seconds up to five minutes.
  • It avoids repeat requests. Answers from the server are cached, and the details of your inverter are saved to disk for six hours, so they aren’t looked up every time.

It also prepares the dashboard’s data after every check, so the window opens instantly.

The dashboard

Open it from the tray icon. Five cards show the essentials: mode, grid, battery, load and solar. A diagram shows where the power is flowing, and below it are all 22 live readings from the inverter.

The History tab shows any day reading by reading, each marked LINE (grid) or BATTERY. It also counts the day’s outages, their total length and the longest one.

Alerts

When the power goes out you get an alert, either a popup or a smaller toast, whichever you prefer. It shows the battery level, the load, the grid voltage and when the outage started. “Don’t Remind” mutes it until the power is back. When the grid returns, a second alert tells you how long the outage lasted.

The tray icon also shows the state at a glance: green on grid power, red on battery.

Under the hood

  • Your login is encrypted. It’s stored with AES-256-GCM, using a key made from your PC’s name, so the saved file won’t work on another computer.
  • It uses the official API. It signs in to ShineMonitor the same way the official mobile app does, instead of scraping the website.
  • Written in Rust. The background work (talking to the server, caching, the tray and alerts) is about 1,900 lines of Rust using Tauri v2. The windows are plain HTML, CSS and JavaScript, with icons and fonts built in.
  • Other brands are easy to add. Any company whose portal runs on ShineMonitor can be added with one line of code. Knox is the first.

What’s next

Support for more inverter brands. If yours uses a ShineMonitor-based portal, open an issue on GitHub and it can be added.
